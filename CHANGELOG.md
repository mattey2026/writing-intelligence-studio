# Changelog

## 1.1.0 (2026-10-09)
- New README with screenshots, architecture diagrams and technical details.
- Workspace: documents reopened from the online library are now editable (fixes Publish and Highest-value edits on reopened documents).
- Workspace: long titles wrap instead of being cut off; the title no longer appears twice in Read mode.
- Workspace: panels show a clear message instead of going blank, and errors are recorded privately for troubleshooting.
- Workspace: faster, memory-safe tracked changes for long documents; the writing area grows with the text.

## 1.0.0 (2026-10-09)
First public release.
- `writing-studio` skill: nine-step editorial workflow, seven personas, depth and reading-level targets, citation rules, originality rules, keyword, hashtag and posting-time guidance.
- `text-quality-check` skill: standard-library script for readability, AI-style phrases, sentence metrics and copied-wording detection, with tests.
- `studio-workspace` skill: interactive editor with tracked edits, source library, research suggestions, video embeds, readability and originality panels, private library, version history and exports.
